# Indonesia POS Retail & F&B Engine (Dynamic QRIS, Thermal Receipts, WhatsApp Invoicing)

Dynamic QRIS On-Screen Display, 58/80mm Thermal Receipt Formatting, PPN 12% Breakdown, and WhatsApp Receipts

## Odoo Apps Store

This repository contains the Odoo 18 module package for `airiv_pos_indonesia`.

Required store assets are maintained in:

```text
airiv_pos_indonesia/static/description/
  icon.png
  banner.png
  index.html
```
